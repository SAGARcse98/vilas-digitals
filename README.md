# Vilas Digital's — Photography & Videography Studio (Narasalagi)

Official React + Vite + Tailwind CSS website for **Vilas Digital's**, Main Road, Narasalagi, Dist. Vijayapura, Karnataka (`+91 93800 61887`).

## Features
- **Bilingual (English / ಕನ್ನಡ)** interface with persisted language preference
- **Hero background slideshow** + scroll reveal animations & animated stats counters
- **Filterable Portfolio Gallery** with keyboard (`←` / `→` / `Esc`) & touch-swipe lightbox
- **Interactive Before/After Slider** showcasing color grading & vintage photo restoration
- **Signature Packages & Instant Quote Calculator** with printable PDF rate card & 1-click WhatsApp sharing
- **Client Testimonials & FAQ Accordion** + live Google Maps embed
- **Studio Owner's Kit (`/#/kit`)** — hidden route with live visiting card customizer/printer and English + Kannada WhatsApp/Instagram marketing templates

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production / Vercel

```bash
npm run build
```
